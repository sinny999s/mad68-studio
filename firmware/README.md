# Stock MAD68 HE firmware

The official MadLions firmware for the MAD68 HE RGB, as published by
MadLions, in its upgrade-file format:

- `MAD68HE_RGB_v1.01_factory.bin`
- `MAD68HE_RGB_v1.03.bin`
- `MAD68HE_RGB_v1.05.bin`
- `MAD68HE_RGB_v1.06.bin`

They are © MadLions / Shenzhen Yizhita Technology Co., Ltd. They are **not**
covered by this repository's GPL-3.0 licence, and are included only:

- so a keyboard can be restored to stock (MAD68 Studio → Firmware → Restore
  stock, or MadLions' own updater)
- as test input for `mad68-cfw/tools/pack.py --selftest`
